# Golden Master PDF – MALFUNCTION

Questo file segnaposto indica la directory dove deve essere posizionato
il golden master PDF per il template `MALFUNCTION` (Attestazione malfunzionamento e ripristino).

## Come generare il golden master

1. Eseguire lo scenario con tag `@malfunction @smoke`.
2. Salvare il file scaricato come `expected.pdf` in questa cartella:
```
src/test/resources/it/pagopa/pn/cucumber/visualtest/expected-pdfs/malfunction/expected.pdf
```
