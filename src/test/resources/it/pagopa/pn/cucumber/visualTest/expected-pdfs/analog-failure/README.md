# Golden Master PDF – ANALOG_FAILURE

Questo file segnaposto indica la directory dove deve essere posizionato
il golden master PDF per il template `ANALOG_FAILURE` (Attestato mancato recapito).

## Come generare il golden master

1. Eseguire lo scenario con tag `@analogFailure @smoke`.
2. Salvare il file scaricato come `expected.pdf` in questa cartella:
```
src/test/resources/it/pagopa/pn/cucumber/visualtest/expected-pdfs/analog-failure/expected.pdf
```
