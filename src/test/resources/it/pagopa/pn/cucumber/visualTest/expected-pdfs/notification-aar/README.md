# Golden Master PDF – NOTIFICATION_AAR

Questo file segnaposto indica la directory dove deve essere posizionato
il golden master PDF per il template `NOTIFICATION_AAR` (Avviso di Avvenuta Ricezione standard).

## Come generare il golden master

1. Eseguire lo scenario con tag `@notificationAar @smoke`.
2. Salvare il file scaricato come `expected.pdf` in questa cartella:
```
src/test/resources/it/pagopa/pn/cucumber/visualtest/expected-pdfs/notification-aar/expected.pdf
```
