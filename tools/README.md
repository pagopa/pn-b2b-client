README per i Tool di Utilità Cucumber
========================================

Questo modulo/cartella contiene strumenti da riga di comando (CLI) per la gestione e l'elaborazione di file Cucumber o relative configurazioni.

Esecuzione dello strumento:
--------------------------

1. Tramite IDE:
   Eseguire la classe `it.pagopa.pn.tools.CucumberToolApplication` fornendo come argomento il percorso della cartella da leggere.

2. Tramite riga di comando (java):
   java -cp target/classes it.pagopa.pn.tools.CucumberToolApplication /percorso/alla/cartella
